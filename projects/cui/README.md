# CUI - UI Helper

CXT is a simple command-line based UI engine, designed to handle every aspect you could need in the creation of an UI.

**Part of the CLEARNING project** - A collection of C learning projects. See the [main README](../../README.md) for more information about the overall project.

## Features

- **Automatic Menu Creation**: Just use createMenu() to have a Menu variable and displayMenu() to automatically display a list of all the options.
- **Title Styling**: With displayTitle() you can customize your title so each app you make has a different personality
- **More to be added!!**

## Usage (Work in progress)
